# Theme inspirations

Added 2026-09-10 for Untrace Desktop 1.5.0.

These are independent palette adaptations for an image-cleaning application, not official ports or endorsed releases. No extension code or artwork is bundled. Backgrounds and familiar accent colours take inspiration from the projects below; semantic roles, surface hierarchy and text contrast are adapted for Untrace. In particular, editor comment colours are often too faint for small interface labels, so secondary text is brighter here.

| Untrace theme | Inspiration / original project |
| --- | --- |
| One Dark | [One Dark Pro](https://marketplace.visualstudio.com/items?itemName=zhuangtongfa.Material-theme), Binaryify and contributors; based on Atom One Dark |
| Dracula | [Dracula](https://github.com/dracula/dracula-theme), Zeno Rocha and contributors |
| Tokyo Night | [Tokyo Night](https://marketplace.visualstudio.com/items?itemName=enkia.tokyo-night), enkia |
| Night Owl | [Night Owl](https://marketplace.visualstudio.com/items?itemName=sdras.night-owl), Sarah Drasner and contributors |
| GitHub Dark / Light | [GitHub Theme](https://marketplace.visualstudio.com/items?itemName=GitHub.github-vscode-theme), GitHub and contributors |
| Catppuccin Mocha / Latte | [Catppuccin for VS Code](https://marketplace.visualstudio.com/items?itemName=Catppuccin.catppuccin-vsc), Catppuccin contributors |

The selection draws on established VS Code themes; it is not a measured installation ranking. All themes work offline and use the same native radio controls and shared component styles. Light, Dark, Graphite, Paper, Cobalt and Ember remain available as Untrace originals.
